# HELM

**High-level Execution and Logic Manager**

This public repository is maintained by [The Allsparks](https://github.com/The-Allsparks) (FTC Team **#36117**).

HELM is experimental. It does **not** replace lower-layer safety and does **not** command robot hardware. Do not place HELM in control of a competition robot.

The Phase 0-2 passive scaffold, research, and CI live in the draft pull request on `feature/phase-0-passive-scaffold`.
